### `scripts/data/sqlcipher3.exe` — SQLCipher command-line shell

A prebuilt SQLCipher 4.5.3 shell (SQLite 3.39.4), statically linked with OpenSSL 3.1.0. It came
into this fork with upstream Snapchat_Auto v1.2.1; who built it is not recorded. It is used only as
a fallback to open `gallery.encrypteddb` when no SQLCipher Python binding is installed.

## Carried by the build

- **FreeSimpleGUI** — the GUI toolkit, **LGPL-3.0-or-later**, <https://github.com/spyoungtech/FreeSimpleGUI>.
  The portable EXE compiles it into the one file. LGPL-3 §4(d)(0) is met by the corresponding source
  of this application being public (this repository, with `uv.lock` and `build_nuitka.cmd`), so a
  recipient can rebuild it against a modified FreeSimpleGUI. Its licence text is in
  THIRD_PARTY_LICENSES.txt.
- **opencv-python** — Apache-2.0; its wheel ships FFmpeg as a separate DLL, under the LGPL-2.1
  (licence texts in the wheel's own licence files, listed in THIRD_PARTY_LICENSES.txt).
- **CPython** — the Python runtime, PSF License Agreement, <https://docs.python.org/3/license.html>;
  **Tcl/Tk** — BSD-style, <https://www.tcl.tk/software/tcltk/license.html>.
- **dfjsim_shared_tools** — the optional update check and the MSI build helpers, by this fork's
  maintainer, **GPL-3.0-or-later** (licence text in THIRD_PARTY_LICENSES.txt). It is imported only
  for the update check, which is off unless a folder of builds is configured.
- **Nuitka runtime** — the compiler is AGPL-3.0, and the C runtime it links into the executable is
